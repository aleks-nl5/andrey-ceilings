# Технічне завдання (ТЗ) на розробку веб-додатка «СтеляПро»
**Версія документу:** 1.0  
**Призначення:** Професійний мобільний PWA-додаток для замірника та монтажника натяжних стель (автономна робота на виїздах, розрахунок площ та периметрів, кошторис «під ключ», CRM клієнтів та чистий друк/PDF).

---

## 1. Загальні відомості та мета проєкту

### 1.1. Найменування
- **Повна назва:** «СтеляПро — Робоче місце майстра натяжних стель».
- **Коротка назва:** «СтеляПро» (англ. *CeilingPro*).

### 1.2. Призначення та цільова аудиторія
Додаток призначений для індивідуальних майстрів, замірників, монтажних бригад та компаній із встановлення натяжних стель в Україні та за кордоном.

### 1.3. Основна мета розробки
Забезпечити майстра надійним, швидким інструментом прямо на об'єкті (зі смартфона або планшета), який дозволяє:
1. Точно ввести або накреслити пальцем геометрію кімнати будь-якої складності (кути, стіни, діагоналі).
2. Автоматично розрахувати площу (м²) та периметр (м.п.) за формулою Герона без ручних помилок.
3. Миттєво сформувати кошторис монтажу з урахуванням обраного полотна, профілю, освітлення та додаткових робіт.
4. Вести базу клієнтів та об'єктів з календарем виїздів (заміри, монтажі).
5. Згенерувати суворий чорно-білий документ «Кошторис-Договір» для друку або експорту в PDF.
6. Працювати повністю автономно в режимі офлайн (PWA).

---

## 2. Архітектура та стек технологій

### 2.1. Frontend-стек
- **Базовий фреймворк:** React 19 (TypeScript).
- **Збирач проєкту:** Vite 6.
- **Стилізація:** Tailwind CSS 4 (`@import "tailwindcss";`), кастомна темна та світла теми з підтримкою системного перемикача.
- **Іконки:** Lucide React.
- **Векторна графіка:** Векторний нативний SVG для візуалізації розкрою та діагоналей.
- **Офлайн / PWA:** Service Worker (Workbox / Vite PWA Plugin), Web App Manifest (`manifest.json`), іконки адаптивного розміру.

### 2.2. Збереження даних (Клієнтська БД)
- **Сховище:** `localStorage` браузера з інкапсуляцією через клас `AppStorage`.
- **Автономність:** 100% збереження на пристрої користувача без обов'язкового серверного бекенду.
- **Безпека та бекапи:** Повний експорт бази в JSON-файл та імпорт з JSON із валідацією структури.
- **Експорт контактів:** Експорт карток замовників у формат візитки vCard (`.vcf`).

## 3. Функціональні вимоги та модулі системи

### 3.1. Модуль «Головна панель майстра» (Dashboard)
- **Розумне нагадування дня:**
  - Аналіз поточного дня (`new Date()`).
  - Відображення найближчих подій: термінові заміри на сьогодні, найближчі монтажі.
  - Кнопка швидкого набору номера клієнта (`tel:`) та переходу в картку об'єкта.
- **Швидкі великі плитки дій (Touch Tiles):**
  - «Швидкий замір» (вибір або створення об'єкта -> перехід до редактора).
  - «Калькулятор» (миттєвий прорахунок вартості на місці).
  - «Об'єкти та клієнти» (каталог замовників та договорів).
  - «Налаштування» (керування розцінками та даними майстра).
- **Зведена статистика:** Кількість активних об'єктів, заміряних приміщень та загальна площа полотен.

### 3.2. Модуль «Сенсорне креслення та замір приміщення» (Measurement Editor)
- **Форми приміщень:**
  - Прямокутник / квадрат.
  - Г-подібне (L-подібне, 6 сторін).
  - Складна довільна форма (n-кутник із довільною кількістю кутів).
- **Геометричний та розрахунковий двигун:**
  - Розрахунок площі за методом тріангуляції (формула Герона за довжинами сторін та діагоналями $d_1, d_2$).
  - Підтримка ручного оверрайду площі та периметра (якщо кімната має радіусні виступи чи колони).
  - Облік висоти базового перекриття.
- **Сенсорне полотно креслення (Touch Blueprint):**
  - Інтерактивне переміщення кутів пальцем.
  - Прив'язка до координатної сітки (Snap to grid).
  - Кнопки масштабування (+ / - / 100% скидання).
  - Додавання та видалення вершин/кутів.
  - Візуалізація сторін (A, B, C, D...), діагоналей, ліній світла, ніші під карниз та труб.
- **Облік конструктиву та опцій:**
  - Тип полотна: ПВХ матовий, сатиновий, глянцевий, тканинний Descor, негорючий Teqtum KM2, акустичний тощо.
  - Колір та бренд полотна (наприклад, MSD Premium, Білий 303).
  - Профільна система: Стіновий алюмінієвий, пластиковий, тіньовий EuroKRAAB, ширяючий з LED, трековий SLOTT.
  - Додаткові роботи: Додаткові кути (понад 4), обвід труб опалення, ніша карниза (ПК-5), свердління керамограніту, багаторівневий перехід, криволінійні ділянки.
  - Освітлення: Кількість люстр, точкових світильників GX53, метри світлових ліній.
  - Текстові примітки та прикріплення фотографій об'єкта з камери/галереї.

### 3.3. Модуль «Експрес-калькулятор»
- Швидкий розрахунок вартості однієї кімнати для клієнта на місці без збереження в базу або зі збереженням до існуючого об'єкта.
- Деталізація: Полотно + Профіль + Складність + Опції = Разом «під ключ».
- Кнопка швидкого копіювання комерційної пропозиції для надсилання у WhatsApp/Viber/Telegram.

### 3.4. Модуль «Об'єкти та клієнти» (CRM)
- **Каталог замовників:** ПІБ, телефон, адреса, примітки. Швидкий виклик, перехід у месенджери, пошук, експорт vCard.
- **Картка об'єкта:**
  - Адреса монтажу, тип приміщення (новобудова, квартира, котедж тощо).
  - Статуси договору: Замір -> Розрахунок -> Погоджено -> В монтажі -> Здано -> Оплачено -> Скасовано.
  - Дата заміру та дата монтажу.
  - Список усіх заміряних приміщень (кімнат) із сумами.
  - Фінансовий блок: Загальна сума договору, знижка (%), внесений аванс, залишок до сплати.
  - Кнопка відкриття друку зведеного кошторису.

### 3.5. Модуль «Налаштування»
- **Профіль майстра та компанії (для кошторисів):**
  - Назва компанії / бренду (якщо порожньо — не виводиться).
  - ПІБ майстра (якщо порожньо — не виводиться).
  - Телефон майстра / компанії.
  - Місто / адреса.
  - Email / сайт.
  - Банківські реквізити (IBAN / картка для авансу).
  - Текст гарантійних зобов'язань.
- **Гнучкий прайс-лист:**
  - Редагування цін для всіх стандартних категорій.
  - Можливість видалення будь-яких або всіх варіантів полотен, профілів, робіт та освітлення.
  - Кнопка відновлення стандартних позицій.
  - Додавання власних нестандартних позицій із вибором одиниці виміру (м², м.п., шт) та вартості.
- **Налаштування інтерфейсу:**
  - Тема оформлення: Світла, Темна, Системна.
  - Мова інтерфейсу: Українська (uk), Англійська (en), Російська (ru).
- **Резервне копіювання:** Експорт усієї бази в JSON, імпорт бази, безпечне скидання до демо-даних.

### 3.6. Модуль «Друк та генерація PDF-документа»
- Суворий чорно-білий друкарський формат A4 (`window.print()` / Зберегти як PDF).
- **Структура документа:**
  1. Шапка документа: Текстова інформація про компанію/майстра (тільки заповнені поля).
  2. Номер договору, дата та статус.
  3. Блок замовника та адреси об'єкта (чистий текст без громіздких прямокутних карток).
  4. Перелік приміщень:
     - Назва кімнати, площа, периметр, кількість кутів.
     - Повнорозмірна векторна векторна схема стелі (без напливання на таблицю, висота адаптована під 280px).
     - Повна таблиця розцінок та обсягів робіт.
     - Підсумок по кожній кімнаті.
  5. Загальний підсумок об'єкта: Сума матеріалів і монтажу, знижка, загальна вартість договору, внесений аванс, точна сума до сплати після монтажу.
  6. Реквізити для оплати та гарантійні зобов'язання.
  7. Місце для підпису замовника та виконавця.
- Режими друку: Друк окремої обраної кімнати або наскрізний зведений кошторис по всіх кімнатах об'єкта.

## 4. Вимоги до інтерфейсу та дизайну (UI / UX)

1. **Мобільна ергономіка (Mobile First):**
   - Великі тач-зони для керування пальцем однієї руки на виїзді (Touch target $\ge 44 \times 44$ px).
   - Віртуальний цифровий блок введення чисел (Numpad) з кнопками швидкого кроку (±0.1м, ±0.5м).
2. **Контрастність тем:**
   - Темна тема: насичений slate-950 із неоновими ціановими акцентами для роботи в темних приміщеннях без оздоблення.
   - Світла тема: м'який фон slate-50, білі картки, чіткий темно-графітовий текст slate-900 (жодного білого тексту на білих поверхнях).
3. **PWA-можливості:**
   - Можливість додавання на головний екран Android та iOS без завантаження з магазинів застосунків.
   - Кешування ассетів для повноцінної роботи без зв'язку.
