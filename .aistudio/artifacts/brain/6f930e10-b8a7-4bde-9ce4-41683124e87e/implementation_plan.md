# Комплексне оновлення додатку «СтеляПро» (План реалізації)

Оновлення додатку спрямоване на підвищення щоденного комфорту майстра на виїздах: кардинальна перебудова генерації чистого PDF-кошторису без збоїв верстки, створення зручного головного екрана з великими кнопками швидкої навігації та актуальними нагадуваннями, компактний перегляд об'єктів з детальним розкриттям, стабілізація сенсорного малювання схем без стрибків масштабу, повноцінне керування позиціями та цінами в прайсі, а також **налаштування профілю майстра та компанії з динамічним приховуванням порожніх полів у кошторисах**.

---

## Підтверджені рішення користувача

> [!IMPORTANT]
> Узгоджені вимоги та архітектурні рішення:
> 1. **Профіль майстра та компанії**: Додається розділ налаштувань у вкладці «Опції» (ПІБ майстра, назва фірми/бренду, телефон, місто/адреса, сайт або соцмережі, реквізити/IBAN, текст примітки/гарантії). **Якщо поле не заповнене — воно повністю ігнорується і не відображається в PDF-кошторисі**.
> 2. **Головний екран**: Створюється як окрема головна стартова вкладка **«Панель майстра»** (Dashboard) з великими плитками навігації та блоком запланованих подій.
> 3. **Експорт у PDF**: Підтримуватиметься друк як **окремого вибраного приміщення**, так і **зведеного кошторису по всіх кімнатах об'єкта** з фінальним підсумком.
> 4. **Редактор прайс-листа**: Реалізується повний функціонал додавання власних полотен, профілів, робіт та освітлення зі зміною цін і видаленням.

---

## 1. Загальний огляд та цілі

- **Профіль майстра / компанії**: Збереження даних підрядника в локальній базі (`AppStorage`). У PDF-документі та договорі-кошторисі формується професійний блок виконавця. Усі порожні рядки відсікаються без порожніх пропусків чи позначок «не вказано».
- **Чистий друк та PDF-кошторис**: Відмова від плаваючих градієнтних блоків у друці. Документ формується в суворому друкарському стандарті A4: фірмова шапка (майстер + замовник), чітка векторна схема кімнати (жорстко обмежена за висотою, без напливання на таблиці), табличні розрахунки матеріалів та монтажу, фінальний підсумок. Для об'єктів з кількома кімнатами генерується наскрізний зведений кошторис.
- **Ергономічний головний екран (Панель майстра)**: Робоче місце замірника з великими кнопками-плитками для натискання пальцем однією рукою («Швидкий замір», «Калькулятор», «Об'єкти та клієнти», «Прайс-лист») і розумною карткою найближчих замірів/монтажів згідно з поточною датою.
- **Компактні картки об'єктів**: Список об'єктів стає лаконічним і легким для швидкого скролінгу (адреса, дата, клієнт, статус, сума). При виборі об'єкта відкривається детальна панель із переліком усіх кімнат, фотографіями, кнопками швидкого дзвінка та друку.
- **Стабільне сенсорне малювання (Touch Blueprint)**: Усунення зворотного зв'язку між рухом вершин і зміною розмірів кімнати, що спричиняло перерахунок коефіцієнта масштабу та "скакання" координат. Впровадження стабільної сітки з ручними кнопками масштабування (+ / - / скинути масштаб).
- **Гнучкий прайс-лист**: Можливість додавати унікальні матеріали (спеціальні кольори, бренди полотен), нестандартні профілі (тіньові, ширяючі, безщілинні), розцінки на додаткові роботи та підсвітку.

## 2. Користувацький досвід та інтерфейс (UX / UI)

### 2.1. Профіль майстра та компанії (Вкладка «Опції»)
- Спеціальна секція **«Дані майстра та компанії для кошторисів»**:
  - Назва компанії / бренду (наприклад, *«Преміум Стеля»*).
  - ПІБ майстра або контактної особи (наприклад, *«Олександр Мельник»*).
  - Контактний номер телефону (з швидким набором).
  - Адреса офісу / місто або робочий регіон.
  - Реквізити / IBAN (для внесення авансу клієнтом).
  - Гарантійні зобов'язання / стандартна примітка (наприклад, *«Гарантія на полотно 10 років, на монтажні роботи 3 роки»*).
- **Поведінка**: Будь-яке поле є опціональним. Якщо майстер не заповнив реквізити чи назву компанії, кошторис формується компактно без пустих місць, показуючи лише наявні контакти та дані замовника.

### 2.2. Стартовий екран «Панель майстра»
- **Великі плитки швидких дій (Touch Cards)**:
  - 📏 **Новий замір**: Відкриває модальне вікно вибору/створення об'єкта або прямий перехід до редактора заміру.
  - 🧮 **Експрес-калькулятор**: Миттєвий прорахунок вартості кімнати для клієнта на місці.
  - 🏢 **Об'єкти та замовники**: Перехід до каталогу з пошуком та фільтрами.
  - ⚙️ **Прайс та налаштування**: Керування цінами та параметрами додатка.
- **Розумна підказка по даті (Сьогодні & Найближчі)**:
  - Автоматичний розрахунок за поточним днем (`new Date()`).
  - Відображення найближчого за часом об'єкта (наприклад: *«Сьогодні о 14:00 — замір: вул. Хрещатик 15»* або *«Найближчий монтаж: 22 жовтня»*).
  - Швидка дія в один дотик: відкрити телефон клієнта або перейти до заміру об'єкта.

### 2.3. Оновлений список об'єктів та детальний перегляд
- **Картка в списку**: Компактний вигляд із чітким статусом, адресою, датою та кількістю кімнат.
- **Детальний екран вибраного об'єкта**:
  - Інформація про замовника з можливістю зателефонувати в один клік.
  - Список усіх замірів/кімнат об'єкта з площею, периметром та вартістю кожної.
  - Кнопка **«Додати кімнату»** та кнопка **«Друк зведеного кошторису»**.
  - Фінансовий блок: Загальна вартість, внесений аванс, залишок до сплати.

### 2.4. Новий друкарський макет PDF-кошторису
- **Шапка документа**:
  - Логотип «СтеляПро», номер кошторису, дата формування.
  - Блок Виконавця (Компанія, Майстер, Телефон, Місто) — тільки заповнені поля.
  - Блок Замовника та Об'єкта: ПІБ, телефон, точна адреса, примітки.
- **Блок кожного приміщення**:
  - Назва кімнати, тип матеріалу, площа (м²), периметр (м.п.), кількість кутів.
  - Векторна схема: чіткі чорні лінії на білому фоні, позначення довжин стін (A, B, C...) та діагоналей, строго ізольований контейнер фіксованої висоти (160-180px), що унеможливлює напливання на текст.
  - Таблиця кошторису: Матеріал полотна, профіль, монтажні роботи, освітлення, додаткові опції (кількість, одиниця, ціна, сума).
  - Проміжний підсумок кімнати.
- **Підсумкова таблиця по всьому об'єкту**:
  - Зведена площа всіх стель, загальний периметр, сума по полотнах, сума монтажу, знижка, аванс та залишок.
  - Реквізити для оплати (якщо вказані в налаштуваннях).
  - Гарантійні умови та місце для підпису замовника і майстра.
- **Друкарські стилі**: Чистий контрастний друкарський дизайн без важких фонових градієнтів, адаптований під альбомний або книжковий формат A4.

### 2.5. Редактор схем дотиком (Touch Blueprint) зі стабільним масштабом
- Відокремлення локальних координат вершин від авто-перерахунку `pixelsPerMeter` під час перетягування.
- Кнопки ручного масштабування в кутку полотна: `+` (збільшити), `-` (зменшити), `100%` (скинути масштаб/відцентрувати).
- Чітка координатна сітка з кроком прив'язки (Snap to Grid).
- Відображення розрахованих довжин сторін та діагоналей безпосередньо біля ребер.

### 2.6. Налаштування та розширення прайс-листа
- Секції в «Опціях»:
  - 🎨 **Полотна**: Назва, одиниця (м²), базова ціна. Кнопка «+ Додати полотно», редагування ціни та назви, видалення.
  - 📐 **Профілі**: Стіновий алюмінієвий, пластиковий, тіньовий EuroKRAAB, ширяючий тощо (грн/м.п.).
  - 🔨 **Додаткові роботи**: Додаткові кути, обвід труб, монтаж бруса, свердління керамограніту тощо.
  - 💡 **Освітлення та карнизи**: Люстри, точкові світильники, світлові лінії, ніші під карниз.
- Збереження в `AppStorage` з можливістю скидання до базових регіональних цін за потреби.

## 3. Ключові архітектурні рішення

- **Друк через оптимізований друкарський DOM-шаблон**:
  - Створення чистого спеціалізованого шаблону друку `PrintEstimateView`, який активується при `window.print()` або відкритті прев'ю.
  - Жодних асинхронних сторонніх важких бібліотек, що ламають мобільний веб — нативний, 100% надійний векторний SVG та друкарські CSS-таблиці.
- **Модель даних профілю майстра та розширеного прайсу**:
  - `MasterProfile`: `{ companyName?: string, masterName?: string, phone?: string, email?: string, address?: string, bankDetails?: string, warrantyNotes?: string }`.
  - Збереження зворотної сумісності для старих записів із підтримкою динамічного масиву користувацьких позицій `CustomPriceItem[]`.
- **Ізоляція стану сенсорного редактора**:
  - Розрив замкненого кола (циклу оновлення пропсів), коли зміна розмірів призводила до скидання масштабу. Координати вершин зберігаються у внутрішньому стані полотна під час активного перетягування.

## 5. План верифікації
1. **Тестування профілю майстра**: Заповнення кількох полів, очищення інших; перевірка, що в PDF з'являються тільки заповнені поля, а порожні не залишають артефактів.
2. **Тестування друку/PDF**: Перевірка друку як для одного заміру, так і для об'єкта з кількома кімнатами у світлій та темній темах, збереження через "Зберегти як PDF" у Chrome та Safari.
3. **Тестування сенсорного редактора**: Переміщення кутів, масштабування кнопками `+`/`-`, перевірка стабільності координат без стрибків.
4. **Тестування панелі майстра**: Перевірка швидких кнопок переходу та віджету найближчого об'єкта.
5. **Тестування прайсу**: Додавання нового полотна, зміна цін, видалення та розрахунок вартості.
6. **Фінальна компіляція**: Перевірка `tsc --noEmit` та `npm run build`.
